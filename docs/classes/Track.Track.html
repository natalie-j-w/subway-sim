    Class Track

    Represents a track (line) connecting two subway stations. Handles creation, positioning, selection, and interaction of track elements as SVG lines.

    Example

    const track = new Track(svgElement, {
      startpoint: station1,
      endpoint: station2
    });
    track.select();

    moveWithStation

    • moveWithStation(station: Station): void

      Moves the track with a given station if it is one of the track's endpoints. Updates the coordinates of both the main track and selection line elements. This method is called when a connected station is moved.

      Parameters

      • station: Station

        The station that has been moved

      Returns void

      Returns early if station is not an endpoint of this track

      Remarks

      Updates x1/y1 coordinates if station is the startpoint, or x2/y2 if it's the endpoint.
